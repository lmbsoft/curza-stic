🗄️ Etapa 2 · Consultas SQL

Una base de datos no se «mira»: se le hacen PREGUNTAS. El idioma universal para preguntarle es SQL — el mismo desde 1974, en todos los sistemas del mundo.

Tu primera frase

SELECT * FROM socios

se lee: «mostrame TODAS las columnas (*) de la tabla socios».

Piezas que vas a sumar

  • SELECT nombre, apellido — elegir columnas.
  • WHERE barrio = 'Centro' — filtrar filas (textos entre comillas simples).
  • AND / OR — combinar condiciones.
  • ORDER BY cuota_mensual DESC — ordenar (DESC = de mayor a menor).
  • LIMIT 3 — solo las primeras n filas.

El motor te avisa en español si algo está mal escrito. Las misiones aceptan CUALQUIER consulta que produzca el resultado pedido.
